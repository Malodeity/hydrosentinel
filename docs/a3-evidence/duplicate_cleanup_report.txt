Duplicate WSA records: before and after (2026-09-19)

Cause: etl/load.py joined the DWS reports on the exact name string, and the reports spell the same authority differently
("Alfred Nzo DM" vs "Alfred Nzo District Municipality"), so one authority became two rows.

Fix: etl.load.merge_sources now joins on an authority key (province + name with suffixes stripped + metro aliases),
etl.load.upsert_wsa_rows matches existing rows on the same key, and etl/dedupe_wsa.py merged the existing rows.
A pg_dump backup was taken first. Tests: tests/test_wsa_dedupe.py (7) and tests/test_data_labels.py (3).
